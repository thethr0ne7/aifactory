# System Prompt Pattern Lab

## Purpose

Study public system-instruction architectures to extract reusable design patterns for agent reliability without copying proprietary prompts or bypassing restrictions.

## Activate when

Improving agent instructions, tool routing, memory policy, quality loops, hallucination controls or modular system design.

## Workflow

`PUBLIC PATTERN → EXTRACT → ABSTRACT → VERIFY → INTEGRATE → EVAL → REUSE`

1. Use only legitimately public material.
2. Identify the behavioral pattern rather than copying wording.
3. Abstract it into a vendor-neutral rule.
4. Check for conflicts with factory safety, evidence and routing policies.
5. Implement as the smallest local instruction or gate.
6. Evaluate against the existing baseline.
7. Record provenance and adopted behavior.

## Guardrails

- Do not seek hidden/private system prompts.
- Do not reproduce protected prompts wholesale.
- Do not use the lab to weaken product/safety restrictions.
- Patterns are valuable only when verified by behavior/evals.
