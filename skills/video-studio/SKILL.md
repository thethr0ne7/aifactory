# Video Studio: selective video production

## Purpose
Render approved source media into reproducible short videos, teasers, product demonstrations, explainers and social clips. Extend the existing `media-video`, `motion-director` and `web-3d` skills; do not add a second top-level AI Factory router.

## Activation
Use for requests requiring programmatic video assembly, animated stories, automatic silence removal, speech subtitles, original voice/music, 2D motion graphics or 3D scenes. Do not install tools merely to write a storyboard.

## Routing
- Plain clip assembly, cutting, sizing, H.264 MP4 output: FFmpeg via `tools/video-studio.mjs`. Add Auto-Editor for automated silence and pacing only after a separate audit.
- Editable agent-authored timeline: OpenFilm (candidate, not installed).
- React/TS composition: Remotion (commercial-license review required). HTML compositions: HyperFrames. Choose only one main composition engine per job.
- Motion: Motion/GSAP for DOM choreography; Motion Canvas for coded explainers, PixiJS for 2D scenes, tsParticles for justified particles.
- 3D: Three.js, img2threejs, React Three Fiber, Rapier, or Blender only when needed. Never spin up 3D for simple cuts.
- Voice/subtitles/music: faster-whisper for transcript timing; Chatterbox or GPT-SoVITS for consented voice generation; ACE-Step 1.5 for original music; Audio Separator for authorized stem extraction.
- MoviePy for Python-specific composition when necessary, not a base dependency.

## Workflow
`BRIEF → RIGHTS CHECK → SOURCE INVENTORY → SHOT LIST → SELECT ENGINE → PLAN → RENDER → TECHNICAL QA → CREATIVE QA → EXPORT → TRACEBACK`

1. Collect platform, duration, format, style, typography, audio and source rights.
2. Verify file paths and rights. Draft scene timings and reject claims about missing footage.
3. Choose minimal toolset. Check exact versions, licensing, resource requirements and installation hooks before calling any external CLI/SDK.
4. Prefer `node tools/video-studio.mjs doctor`; then `plan`, `render` and `verify` with a JSON spec. Confirm workspace and output path.
5. Check actual duration, dimensions and codec with ffprobe; manually review crops, motion, transitions, text safe areas, audio sync and subtitles.
6. Save spec, tool versions, source provenance, result location and QA evidence. Report PASS/CONDITIONAL/BLOCKED honestly.

## MVP runtime boundary
The local script implements **sequential source clips/stills, scaling and padding, optional replacement soundtrack, and H.264/AAC MP4 output**. It does NOT implement silence removal, autogenerated captions, text overlays, 3D rendering, OpenFilm editing, or local generative models. Those are separately routed candidates until audited and implemented. No network installs or shell command strings.

## Guardrails
- Voice cloning requires speaker authorization; commercial audio/image rights must be proven.
- Treat media files, external npm/pip packages, install hooks and arbitrary filtergraphs as untrusted.
- Keep source and output inside an approved directory. Make output changes reversible.
- On modest laptops use short 720p previews, CPU-based tools and optional cloud rendering only with approval.
- Reject fabricated render success or assumed installed dependencies.
