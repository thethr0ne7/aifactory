# UI Taste Gate

## Purpose

Reject technically valid interfaces that are visually generic, cluttered, inconsistent or weak for the product's audience.

## Activate when

Any end-user UI or visual product surface is ready for review.

## Checks

- clear visual hierarchy;
- intentional typography;
- spacing rhythm;
- restrained color use;
- coherent component geometry;
- useful whitespace;
- recognizable product/brand character;
- no decorative noise competing with primary actions;
- mobile-first quality;
- appropriate motion and imagery.

## Workflow

1. Compare UI to product brief and Brand/Design DNA.
2. Identify the three highest-impact taste failures.
3. Distinguish structural issues from polish issues.
4. Repair hierarchy/layout before decorative details.
5. Pass final output to Visual Fidelity and accessibility/performance checks.

## Guardrails

Taste is not arbitrary preference: findings must point to hierarchy, consistency, usability, brand fit or visual coherence. Do not over-polish low-value screens while core usability is broken.
