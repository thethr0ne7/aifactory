# Research Toolbelt

## Purpose

Choose research tools by evidence need rather than by convenience. Tools discover, transform or validate evidence; they are not authorities themselves.

## Activate when

Research & Truth needs broader discovery, academic literature, historical snapshots, reverse-image checks, technical validation or source comparison.

## Tool classes

- **Official web / first-party sources** — authoritative current rules, documentation and owner statements.
- **Academic discovery** — Elicit, Consensus, Semantic Scholar, Connected Papers, SciSpace or equivalent tools for finding relevant research.
- **Historical snapshots** — web archives for proving what a page said at a past time.
- **Reverse-image search** — provenance/context checks for visual claims.
- **Technical validators** — purpose-built validators for code, formats, DNS/security/status or structured data.

## Workflow

1. State the evidence gap.
2. Select the narrowest tool class that can close it.
3. Retrieve candidate sources.
4. Return to the original/primary source whenever available.
5. Record provenance and freshness.
6. Feed evidence into `research-truth`; do not make the tool output the final authority.

## Guardrails

- Do not use paywall-bypass or piracy sources as evidence infrastructure.
- Archive copies establish historical content, not current validity.
- Academic aggregators help discovery but do not replace reading the underlying paper.
- Reverse-image similarity does not prove intent, identity or chronology by itself.
- If a tool is unavailable, degrade gracefully to another evidence path and state the limitation.
