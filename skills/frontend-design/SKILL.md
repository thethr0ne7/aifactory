# Frontend Design

## Purpose

Turn product intent and Design DNA into distinctive, usable production UI without generic AI visual defaults.

## Activate when

Building or redesigning websites, dashboards, Telegram Mini Apps, landing pages, app screens or reusable UI components.

## Workflow

1. Define user goal and primary action.
2. Load relevant Design DNA / Brand DNA.
3. Establish information hierarchy before decoration.
4. Design mobile-first; expand to tablet/desktop after the narrow layout works.
5. Choose typography, spacing, component shape and visual rhythm intentionally.
6. Implement states: loading, empty, error, success, disabled, focus and hover where applicable.
7. Run accessibility, overflow, content-density and touch-target checks.
8. Hand off to Visual Fidelity for comparison and repair.

## Anti-slop rules

Avoid defaulting to oversized centered hero copy, arbitrary gradients, excessive glassmorphism, uniform rounded cards, decorative blobs, fake metrics or visual complexity without product purpose.

## Output contract

Deliver production-ready layout/components plus design rationale, responsive behavior and state coverage.

## Gates

- mobile-first;
- readable hierarchy;
- keyboard/focus accessibility;
- touch targets;
- responsive overflow;
- performance-conscious assets;
- visual fidelity.
