# Compound Skill Loop

## Purpose

Turn repeated successful workflows and recurring failures into small reusable improvements to the factory.

## Activate when

A workflow repeats, an error recurs, or a project produces a generalizable pattern that would reduce future work.

## Workflow

`OBSERVE → EXTRACT PATTERN → GENERALIZE → TEST → COMPARE → REGISTER`

1. Capture the concrete success/failure evidence.
2. Extract the reusable rule without product-specific noise.
3. Decide whether the rule belongs in an existing skill or warrants a new one.
4. Create a focused eval that demonstrates the improvement.
5. Compare against the current baseline.
6. Register only if the change improves capability without excessive context cost.

## Guardrails

- No autonomous self-rewriting of the factory.
- No skill creation merely because one task was unusual.
- Prefer improving an existing skill over proliferating near-duplicates.
- Security/provenance gates remain mandatory for external patterns.
