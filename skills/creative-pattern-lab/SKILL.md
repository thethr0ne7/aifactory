# Creative Pattern Lab

## Purpose

Use experimental creative-coding and premium visual references as a pattern library without introducing a second orchestration system.

## Activate when

A design task needs unconventional interaction, motion or visual treatment after the core Frontend Design / Motion / Brand rules are already defined.

## Workflow

1. Identify the specific visual problem the core design stack does not solve.
2. Search experimental patterns for one relevant mechanism.
3. Extract the mechanism, not the surrounding framework or agent architecture.
4. Reimplement it under the project's Brand DNA, accessibility and performance constraints.
5. Compare against a simpler baseline.
6. Keep the experimental pattern only if it measurably improves the experience.

## Guardrails

- Pattern donor only; never a competing factory control plane.
- No novelty for novelty's sake.
- Avoid stacking multiple experimental effects on the same screen.
- Accessibility and performance gates remain mandatory.

## Provenance

Inspired by creative-coding patterns in `AThevon/genjutsu`; adoption mode is `pattern-only`.
